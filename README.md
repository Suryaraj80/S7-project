# ANNA AGRI AI (AAA PLATFORM FOR FARMERS)

**ANNA AGRI AI (AAA Platform)** is an intelligent agricultural technology and direct farmgate commerce ecosystem built specifically for Tamil Nadu farmers, while connecting consumers, cooperative societies, and buyers from across India (Kerala, Karnataka, Andhra Pradesh, Maharashtra, etc.) directly to farmers.

---

## 🌟 Core Flagship Features

### 1. 🌦️ Tamil Nadu District Agro-Weather Report
- Real-time microclimate metrics for all 38 Tamil Nadu districts (Thanjavur, Madurai, Coimbatore, Salem, Tiruchirappalli, Tirunelveli, Erode, etc.).
- Temperature, relative humidity, wind speed, and 5-day rain probabilities.
- Localized agro-meteorological advisories (e.g. Kuruvai top dressing timing, pest prophylactic sprays, banana bunch propping).

### 2. 🧪 TNAU Soil Test Slot Booking & Digital Token Generator
- Direct slot booking at nearest TNAU research stations, mobile soil testing vans, and district laboratories.
- Pre-filled farmer survey number, patta info, planned crop, and soil type.
- 100% Free government-subsidized testing covering 12 nutrient parameters (N, P, K, pH, EC, Organic Carbon, Zinc, Boron, Iron, Manganese, Copper, Sulphur).
- Instant printable appointment slip & **Share via WhatsApp** token confirmation.
- Scientific 4-step sample collection protocol guide (V-cut zigzag method, 15cm plough depth, quartering method, shade drying).

### 3. 🌾 Tamil Nadu Crop Recommendation Engine
- Scientific crop variety matching based on Tamil Nadu agro-climatic zones and soil types (Alluvial, Clayey, Red soil, Black soil, Sandy Loam).
- Sowing season filters: **Kuruvai (May - July)**, **Aadi Pattam (July - Aug)**, **Samba (Aug - Oct)**, **Navarai / Summer**.
- Net profit projections per acre and expected yields.
- Direct links to associated government seed and irrigation subsidy packages (e.g. TN Kuruvai Package, PDMC Drip Subsidy).

### 4. 🏪 Shops & Farm Machinery Depots Nearby (அங்காடிகள்)
- Directory of verified Primary Agricultural Cooperative Credit Societies (PACCS), Government Agricultural Extension Centres (AEC), and Custom Hiring Machinery Centres (CHC / e-Vaadagai).
- Inventory stock visibility (Urea, DAP, Potash, Certified Paddy Seeds, Bio-fertilizers, 45HP Tractors, Power Tillers, Combine Harvesters).
- Direct phone call links, shop addresses, and distance tags.

### 5. 🛒 Farmer-Fixed Price Marketplace (உழவர் நேரடி சந்தை)
- **Zero Middlemen**: Tamil Nadu farmers list fresh harvest with **their own fixed prices** (₹/kg, ₹/quintal, ₹/bag).
- **Inter-State Direct Commerce**: Residential societies, housing associations, and bulk buyers from Kerala, Karnataka, Andhra Pradesh, and other states order directly at farmgate prices.
- Inter-state transport logistics support, organic certification tags, minimum order quantities, and direct farmer WhatsApp contact.

### 6. 📱 'Share via WhatsApp' Integration
- Embedded in **SchemeDetailModal**: One-click sharing of verified scheme names, benefit amounts, eligibility, and official application links with fellow farmers.
- Embedded in **Recommendation Cards** and **Soil Test Tokens**.

### 7. 🤖 ANNA AGRI AI Advisor (Voice & Multilingual)
- Dual AI chatbot powered by `@google/genai` (Gemini API) and local intelligent retrieval fallback.
- Native trilingual fluency: **English, தமிழ் (Tamil), and हिन्दी (Hindi)**.
- Integrated Web Speech API for voice dictation and Text-to-Speech audio read-aloud.

### 8. 📜 Government Schemes Recommendation Engine
- 15+ verified Central & Tamil Nadu State agricultural welfare schemes.
- Explainable matching score with transparent criteria breakdown.
- Dynamic "What-If" simulator, digital document readiness locker, subsidy calculators, seasonal calendars, and 72-hour calamity claim protocols.

## 🚀 Quick Start & Development

```bash
# Install dependencies
npm install

# Run full-stack dev server (Express backend + Vite frontend on port 3000)
npm run dev

# Run TypeScript check
npm run lint

# Build production bundle
npm run build
```
